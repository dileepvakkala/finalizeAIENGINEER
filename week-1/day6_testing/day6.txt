Session 1 (6 AM – 8 AM)
Synchronous Programming

In synchronous programming, tasks execute one after another.

Example:

import time

def task1():
    print("Task 1 Started")
    time.sleep(3)
    print("Task 1 Completed")

def task2():
    print("Task 2 Started")
    time.sleep(2)
    print("Task 2 Completed")

task1()
task2()

Output:

Task 1 Started
(wait 3 sec)

Task 1 Completed

Task 2 Started
(wait 2 sec)

Task 2 Completed

Total Time:

5 seconds
Problem with Sync

Imagine:

User Request
   ↓
DB Call (3 sec)
   ↓
External API (2 sec)
   ↓
Response

Total:

5 sec

User waits.

Asynchronous Programming

Allows other tasks to run while waiting.

Example:

import asyncio

async def task1():

    print("Task 1 Started")

    await asyncio.sleep(3)

    print("Task 1 Completed")


async def task2():

    print("Task 2 Started")

    await asyncio.sleep(2)

    print("Task 2 Completed")


async def main():

    await asyncio.gather(
        task1(),
        task2()
    )

asyncio.run(main())

Output:

Task1 Started
Task2 Started

Task2 Completed
Task1 Completed

Total:

3 seconds

instead of 5.

async Keyword

Defines asynchronous function.

async def fetch_data():
    pass
await Keyword

Pauses current coroutine until task completes.

await fetch_data()
Event Loop

Heart of asyncio.

Event Loop

Task1
Task2
Task3
Task4

Runs efficiently

3. What is Event Loop?

Core engine that schedules async tasks.

4. What is async keyword?

Defines coroutine.

async def process():
5. What is await?

Waits for async operation without blocking thread.

6. What is Coroutine?

Function defined using:

async def
7. What is asyncio.gather()?

Runs multiple coroutines concurrently.

await asyncio.gather(
    task1(),

9. When should Async NOT be used?

10. Difference Between Multithreading and Async?

Async:

Single thread
Event loop

Multithreading:

Multiple threads
11. Difference Between Concurrency and Parallelism?

Concurrency:

Task A
Task B
Task C

Managed together.

Parallelism:

CPU1 → Task A
CPU2 → Task B

Runs simultaneously.
