Session 2 (11:00 AM – 1:00 PM)
SQLAlchemy Relationships
Customer Model
from sqlalchemy import Column
from sqlalchemy import Integer
from sqlalchemy import String
from sqlalchemy.orm import relationship

class Customer(Base):

    __tablename__ = "customers"

    id = Column(Integer, primary_key=True)

    name = Column(String)

    accounts = relationship(
        "Account",
        back_populates="customer"
    )
Account Model
from sqlalchemy import Column
from sqlalchemy import Integer
from sqlalchemy import String
from sqlalchemy import ForeignKey
from sqlalchemy.orm import relationship

class Account(Base):

    __tablename__ = "accounts"

    id = Column(Integer, primary_key=True)

    account_number = Column(String)

    customer_id = Column(
        Integer,
        ForeignKey("customers.id")
    )

    customer = relationship(
        "Customer",
        back_populates="accounts"
    )

Repository Layer

Handles database operations.

class CustomerRepository:

    def get_all(self, db):

        return db.query(Customer).all()
Service Layer

Handles business logic.

class CustomerService:

    def get_customers(self, db):

        return repository.get_all(db)

Interview Questions
What is a Foreign Key?

A column that references another table's primary key.

Difference Between Primary Key and Foreign Key?
Primary Key	Foreign Key
Unique identifier	References another table
Unique	Can repeat
One per table	Multiple allowed
What is One-to-Many Relationship?

One record in parent table can have many child records.

Example:

Customer
    ↓
Accounts
What is SQLAlchemy Relationship?

A way to map related tables as Python objects.

Why use Repository Pattern?

Separates database logic from business logic.

Why use Service Layer?

Contains business rules.

Example:

Loan approval logic
Account validation
Fraud checks
Difference Between Router and Service?

Router:

Handles HTTP requests

Service:

Handles business logic
