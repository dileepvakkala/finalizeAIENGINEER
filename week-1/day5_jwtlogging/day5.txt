Dependency Injection (Depends)

Instead of creating DB connections manually:

db = SessionLocal()

FastAPI provides Dependency Injection:

from fastapi import Depends
from sqlalchemy.orm import Session

@app.get("/customers")
def get_customers(
    db: Session = Depends(get_db)
):
    pass

Update Customer Repository
@staticmethod
def update(db, customer_id, customer):

    existing = db.query(Customer).filter(
        Customer.id == customer_id
    ).first()

    if not existing:
        return None

    existing.name = customer.name
    existing.city = customer.city

    db.commit()
    db.refresh(existing)

    return existing
Delete Customer
@staticmethod
def delete(db, customer_id):

    customer = db.query(Customer).filter(
        Customer.id == customer_id
    ).first()

    if not customer:
        return False

    db.delete(customer)
    db.commit()

    return True

@app.exception_handler(Exception)
async def global_exception_handler(
        request: Request,

Dependency Injection
1. What is Dependency Injection in FastAPI?

Answer:
Dependency Injection (DI) is a design pattern where dependencies are provided to a component instead of being created inside it.

Example:

@app.get("/customers")
def get_customers(
    db: Session = Depends(get_db)
):
    pass

Benefits:

Loose coupling
Easier testing
Better maintainability
2. Why is Dependency Injection important?

Without DI:

def get_customer():
    db = SessionLocal()

Problems:

Tight coupling
Hard to mock during testing
Repeated code
3. How does FastAPI's Depends() work internally?

FastAPI builds a dependency graph and resolves dependencies before executing the endpoint.

Flow:

Request
 ↓
Dependency Resolver
 ↓
get_db()
 ↓
Endpoint
4. What happens if get_db() fails?

FastAPI stops request processing and returns an error response.

5. Can dependencies depend on other dependencies?

Yes.

Example:

get_current_user()
    ↓
verify_token()
    ↓
get_db()
Database Session Management
6. Why use yield inside get_db()?
def get_db():
    db = SessionLocal()

    try:
        yield db
    finally:
        db.close()

Ensures DB connection is closed after request completion.

7. What happens if we don't close DB sessions?

Problems:

Connection leaks
Connection pool exhaustion
Application slowdown
8. Difference between Session and Engine?

Engine:

Manages database connections

Session:

Manages transactions
9. What is connection pooling?

Reusing database connections instead of creating a new one per request.

Benefits:

Better performance
Lower latency
10. How do you optimize DB connections in production?
Connection pooling
Query optimization
Indexing
Read replicas
