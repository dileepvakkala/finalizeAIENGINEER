Session 2 (11 AM – 1 PM)
Creating Tools
from langchain.tools import tool

@tool
def get_balance(
    account_id: str
):
    """
    Fetch account balance
    """

    balances = {
        "1001":50000,
        "1002":70000
    }

    return balances.get(
        account_id,
        "Not Found"
    )
Create Agent
from langchain.agents import (
    create_tool_calling_agent
)

Initialize Agent

agent = create_tool_calling_agent(
    llm,
    tools,
    prompt
)
Create Executor
from langchain.agents import (
    AgentExecutor
)

executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True
)

Run Agent

executor.invoke(
    {
        "input":
        "What is balance of account 1001?"
    }
)

Expected Flow

Thought:
Need account balance

Action:
get_balance

Observation:
50000

Answer:
Balance is 50000

Interview Questions
What is an Agent?

An AI system that can reason and use tools to complete tasks.

Difference between Agent and Chain?

Chain is fixed.

Agent dynamically decides actions.

What is Agent Executor?

Component that manages tool execution and reasoning loops.

What is ReAct?

Reason + Act.

Agent thinks, performs actions, observes results, and continues reasoning.

What is Tool Calling?

Allowing an LLM to invoke external functions.

Can an Agent use multiple tools?

Yes.

Agents can execute several tools before producing an answer.

What is a Multi-Agent System?

A system with specialized agents collaborating on tasks.

Why are Agents important?

They enable automation, decision-making, and interaction with external systems.

What is Agent Memory?

Memory used by agents to retain conversation context.

What is an Observation?

The output returned by a tool.
