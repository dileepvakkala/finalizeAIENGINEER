Streaming Code
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role":"user",
            "content":"Explain RAG"
        }
    ],
    stream=True
)

for chunk in stream:
    print(
        chunk.choices[0].delta.content,
        end=""
    )

FastAPI Integration
from fastapi import FastAPI
from openai import OpenAI

app = FastAPI()

client = OpenAI()

Endpoint

@app.post("/chat")
def chat(query: str):

    response = (
        client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {
                    "role":"user",
                    "content":query
                }
            ]
        )
    )

    return {
        "answer":
        response.choices[0]
        .message.content
    }

Interview Questions
What is the OpenAI SDK?

Python library used to interact with OpenAI models.

What is a Chat Model?

A model that processes message-based conversations.

Explain Message Roles.

System: Instructions

User: Input

Assistant: Previous responses

Tool: Tool output

What is Temperature?

Controls randomness and creativity.

Why use low temperature in banking?

For consistent and reliable responses.

What is Streaming?

Returning tokens incrementally rather than waiting for the full response.

What is a Context Window?

Maximum number of tokens a model can process.

What causes high token usage?
Long prompts
Long chat history
Large retrieved context
How do you reduce token cost?
Prompt optimization
Context compression
Retrieval filtering
Summarization
What is a System Prompt?
