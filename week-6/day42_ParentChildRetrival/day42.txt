Day 42 – Parent-Child Retrieval Chunking (Advanced RAG)

This is an advanced RAG technique frequently discussed in senior AI Engineer interviews.

The problem with normal chunking:

Document
   ↓
Chunk
   ↓
Embedding
   ↓
Retrieve

If chunks are small:

High Precision
Low Context

If chunks are large:

High Context
Low Precision

Parent-Child Retrieval solves both problems.

Why Parent-Child Retrieval?

Suppose a banking document contains:

Home Loan Policy

Interest Rate: 8%

Eligibility:
Salary > 50,000

Documents:
PAN
Aadhaar
Salary Slips

Processing Fee:
0.5%
Small Chunk Approach

Chunks:

Chunk 3:

User asks:

What documents are required for home loan?

Problem:

Missing Home Loan Context
Large Chunk Approach

Chunk:

Entire Home Loan Policy

Problem:

Too much information
Less precise retrieval
Parent-Child Retrieval Solution

Store:

Parent Chunk

Large context.

Retrieve:

Child Chunk

Small precise chunk.

Return:

Parent Chunk

to the LLM.

LangChain ParentDocumentRetriever

Most commonly used implementation.

Install:

pip install langchain
Session 1 (6 AM – 8 AM)
Step 1: Load Document
from langchain_community.document_loaders import TextLoader

loader = TextLoader("loan_policy.txt")

documents = loader.load()
Step 2: Create Parent Splitter
from langchain.text_splitter import RecursiveCharacterTextSplitter

parent_splitter = (
    RecursiveCharacterTextSplitter(
        chunk_size=2000,
        chunk_overlap=200
    )
)
Step 3: Create Child Splitter
child_splitter = (
    RecursiveCharacterTextSplitter(
        chunk_size=300,
        chunk_overlap=50
    )
)
Session 2 (11 AM – 1 PM)
Create Vector Store

Example using ChromaDB:

from langchain_chroma import Chroma

vectorstore = Chroma(
    collection_name="banking_docs",
    embedding_function=embeddings
)
Create Doc Store
from langchain.storage import InMemoryStore

store = InMemoryStore()
Create Parent Retriever
from langchain.retrievers import (
    ParentDocumentRetriever
)

retriever = ParentDocumentRetriever(
    vectorstore=vectorstore,
    docstore=store,
    child_splitter=child_splitter,
    parent_splitter=parent_splitter
)
Add Documents
retriever.add_documents(
    documents
)
Retrieval Flow
results = retriever.invoke(
    "Required documents for home loan"
)

Interview Questions
What is Parent-Child Retrieval?

A retrieval strategy where small child chunks are embedded and searched, while larger parent chunks are returned to the LLM.

Why use Parent-Child Retrieval?

To achieve both precise retrieval and rich context.

What is stored in the Vector DB?

Child chunks.

What is stored in the Doc Store?

Parent chunks.

What happens during retrieval?
Query
 ↓
Find Child
 ↓
Get Parent
 ↓
Return Parent
Why not embed only large chunks?

Large chunks reduce retrieval precision.

Why not embed only small chunks?

Small chunks lose context.

What are Parent and Child chunk sizes?

Common values:

Parent: 2000

Child: 300
Which LangChain component implements this?

ParentDocumentRetriever
