Interview Questions
What is Function Calling?

A mechanism allowing LLMs to invoke external functions using structured arguments.

Why use Function Calling?

To interact with APIs, databases, and tools reliably.

What is Structured Output?

A predictable JSON or object response format.

Why use Pydantic?

Validation, serialization, and type safety.

What is JSON Schema?

A definition of expected JSON structure.

What is Output Parsing?

Converting model output into structured data.

Difference between Free Text and Structured Output?
Free Text	Structured
Flexible	Predictable
Hard to Parse	Easy to Parse
Human Friendly	Machine Friendly
What is PydanticOutputParser?

Parses LLM responses into Pydantic objects.

Why are structured outputs important?

They enable automation and integration with backend systems.

Can Agents use Function Calling?

Yes. Modern agents heavily depend on function/tool calling.
