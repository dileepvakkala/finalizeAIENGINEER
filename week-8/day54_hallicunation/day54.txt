Day 54 – Hallucination Detection in RAG & LLM Systems

Hallucination Detection is one of the most important topics for senior AI Engineer interviews and production AI systems.

A hallucination occurs when an LLM generates information that is:

Factually incorrect
Unsupported by retrieved documents
Fabricated
Misleading
What is Hallucination?

User asks:

What is the interest rate for XYZ Home Loan?

Retrieved Context:

Home Loan Processing Fee = 0.5%

LLM Answer:

Interest rate is 8.75%

Problem:

Interest rate was never present in context.

This is a hallucination.

1. No Retrieval

4. Outdated Knowledge

Model knowledge cutoff issue.

Hallucination Types
Type 1: Factual Hallucination
India has 35 states.

Incorrect fact.

Type 2: Citation Hallucination
According to RBI Circular 2025...

No such document exists.

Type 3: Numerical Hallucination
Interest Rate = 7.5%

Actual:

Interest Rate = 8.5%
Type 4: Reasoning Hallucination

Wrong conclusion despite correct facts.

A generated statement not supported by facts or provided context.

What is groundedness?

The degree to which an answer is supported by evidence.

What is faithfulness?

The extent to which generated answers are supported by retrieved context.

What is the difference between relevancy and faithfulness?
Metric	Meaning
Relevancy	Answers the question
Faithfulness	Supported by context
How does CRAG reduce hallucinations?

By validating retrieval quality before generation.

How does Graph RAG reduce hallucinations?

By retrieving structured relationships instead of isolated chunks.
