Why Neo4j?

Traditional SQL:

Customer
Account
Loan
Transaction

To find relationships:

SELECT *
FROM customer c
JOIN account a
ON c.id = a.customer_id
JOIN transaction t
ON a.account_id = t.account_id

Many joins.

Neo4j:

Customer
   |
 OWNS
   |
Account
   |
TRANSFERRED_TO
   |
Account

Relationship traversal is much faster.

Session 1 (6 AM – 8 AM)
Neo4j Core Concepts
Node

Represents an entity.

Examples:

Customer
Account
Loan
Branch
Employee

Customer Node:

{
  "customer_id": 1,
  "name": "Dileep"
}

Cypher:

CREATE (:Customer {
    customer_id: 1,
    name: "Dileep"
})
Relationship

Connects nodes.

Examples:

OWNS
APPROVED_BY
TRANSFERRED_TO
WORKS_AT

Example:

Dileep

↓

OWNS

↓

Account123

Cypher:

MATCH (c:Customer),(a:Account)
WHERE c.customer_id = 1
AND a.account_id = "123"
CREATE (c)-[:OWNS]->(a)
Properties

Metadata stored in nodes.

Customer:

{
  "customer_id": 1,
  "name": "Dileep",
  "city": "Bangalore"
}

Relationship Properties:

TRANSFERRED_TO

can have:

{
  "amount": 10000,
  "date": "2025-01-01"
}

Cypher:

CREATE (a)-[:TRANSFERRED_TO {
    amount:10000,
    date:"2025-01-01"
}]->(b)
Session 2 (11 AM – 1 PM)
CRUD Operations
Create Node
CREATE (:Customer {
  customer_id:1,
  name:"Dileep"
})
Create Account
CREATE (:Account {
  account_id:"ACC123",
  balance:100000
})
Read Node
MATCH (c:Customer)
RETURN c
Update Node
MATCH (c:Customer)
WHERE c.customer_id=1

SET c.city="Bangalore"

RETURN c
Delete Node
MATCH (c:Customer)
WHERE c.customer_id=1

DELETE c

Delete with relationships:

MATCH (c:Customer)
WHERE c.customer_id=1

DETACH DELETE c
Query Relationships

Find customer accounts:

MATCH (c:Customer)-[:OWNS]->(a:Account)

RETURN c,a

Find account owner:

MATCH (c:Customer)-[:OWNS]->(a:Account)

WHERE a.account_id="ACC123"

RETURN c

Session 3 (4 PM – 6 PM)
Neo4j Python Integration

Install:

pip install neo4j

Connect:

from neo4j import GraphDatabase

uri = "bolt://localhost:7687"

driver = GraphDatabase.driver(
    uri,
    auth=("neo4j","password")
)

Create Node:

def create_customer(tx):

    tx.run("""
    CREATE (:Customer {
        customer_id:1,
        name:'Dileep'
    })
    """)

with driver.session() as session:
    session.execute_write(create_customer)

Read Data:

def get_customers(tx):

    result = tx.run("""
    MATCH (c:Customer)
    RETURN c.name
    """)

    return [r["c.name"] for r in result]
Neo4j Browser

Useful commands:

Show all nodes:

MATCH (n)
RETURN n

Show all relationships:

MATCH ()-[r]->()
RETURN r

Count nodes:

MATCH (n)
RETURN count(n)

Interview Questions
What is Neo4j?

A graph database optimized for storing and querying relationships.

What are Nodes?

Entities in the graph.

Examples:

Customer
Account
Loan
What are Relationships?

Connections between nodes.

Examples:

OWNS
APPROVED_BY
TRANSFERRED_TO
What are Properties?

Metadata stored on nodes and relationships.

What is Cypher?

Neo4j's query language.

Difference Between SQL and Neo4j?
SQL	Neo4j
Tables	Nodes
Rows	Nodes
Foreign Keys	Relationships
JOINs	Traversals
Why is Neo4j useful for Graph RAG?

Because it efficiently stores and retrieves entity relationships.

What is a Graph Traversal?

Following relationships between nodes.

Example:

Customer
 ↓
Account
 ↓
Transaction
 ↓
Customer
What is DETACH DELETE?

Deletes node and all associated relationships.
