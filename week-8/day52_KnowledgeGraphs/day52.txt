Traverse Relationships

Neo4j Example

Create Node:

CREATE (:Customer {
    id:1,
    name:"Dinesh"
})

Create Account:

CREATE (:Account {
    account_id:"123"
})

Create Relationship:

MATCH (c:Customer),(a:Account)
WHERE c.id=1
AND a.account_id="123"
CREATE (c)-[:OWNS]->(a)
Query Example

Find Accounts:

MATCH (c:Customer)-[:OWNS]->(a:Account)
RETURN a

Find Transaction Chain:

MATCH p=
(a)-[:TRANSFERRED_TO*]->(b)
RETURN p

Interview Questions
What is a Knowledge Graph?

A structured graph of entities and relationships representing real-world knowledge.

What is an RDF Triple?
Subject
Predicate
Object

Example:

(Dinesh, OWNS, Account123)
What is an Ontology?

A schema defining entity types, relationships, and properties.

What is Entity Resolution?

The process of identifying and merging duplicate entities.

Why use Graph Databases?

They efficiently store and query relationships.

Why is Neo4j popular?

Because it is optimized for graph traversal and relationship queries.

What is Multi-Hop Reasoning?

Following multiple relationships to answer a question.

Example:

Customer

↓

Account

↓

Transaction

↓

Company
How does Knowledge Graph help Graph RAG?

It provides structured relationship-based retrieval.
