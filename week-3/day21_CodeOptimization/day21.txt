Session 3 (4 PM – 6 PM)
SQLAlchemy Optimization
Problem
customers = (
    db.query(Customer)
      .all()
)

If table has:

10 Million Rows

Huge memory issue.

Use Pagination
customers = (

    db.query(Customer)

    .offset(0)

    .limit(50)

    .all()
)
Avoid SELECT *

Bad:

db.query(Customer).all()

Good:

db.query(
    Customer.id,
    Customer.name
)
N+1 Query Problem

Bad:

customers = (
    db.query(Customer)
      .all()
)

for customer in customers:

    print(
        customer.accounts
    )

Produces:

1 + N Queries
Solution
from sqlalchemy.orm import joinedload
customers = (

    db.query(Customer)

    .options(
        joinedload(
            Customer.accounts
        )
    )

    .all()
)

SQL Optimization Techniques
EXISTS instead of IN

Bad:

SELECT *

FROM customers

WHERE id IN
(
SELECT customer_id
FROM accounts
);

Better:

SELECT *

FROM customers c

WHERE EXISTS
(
SELECT 1
FROM accounts a

WHERE a.customer_id=c.id
);
Avoid SELECT *

Bad:

SELECT *
FROM customers;

Good:

SELECT id,name
FROM customers;
