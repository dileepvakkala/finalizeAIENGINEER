Relationships
One Customer → Many Accounts
Customer Model
from sqlalchemy.orm import relationship

class Customer(Base):

    __tablename__ = "customers"

    id = Column(
        Integer,
        primary_key=True
    )

    accounts = relationship(
        "Account",
        back_populates=
        "customer"
    )
Account Model
from sqlalchemy import ForeignKey
from sqlalchemy.orm import relationship

class Account(Base):

    __tablename__ = "accounts"

    id = Column(
        Integer,
        primary_key=True
    )

    customer_id = Column(
        Integer,
        ForeignKey(
            "customers.id"
        )
    )

    customer = relationship(
        "Customer",
        back_populates=
        "accounts"
    )

Performance Questions
36. What is N+1 Query Problem?

Example:

customers = db.query(Customer).all()

for customer in customers:
    print(customer.accounts)

Produces:

1 Query for customers
N Queries for accounts
37. How do you solve N+1 problem?

Use:

joinedload()
38. What is Lazy Loading?

Load related data only when accessed.

39. What is Eager Loading?

Load related data immediately.

40. Which is faster?

Depends on use case.

Usually eager loading avoids N+1.

Connection Pooling
41. What is Connection Pooling?

Reuse existing database connections.

42. Why is pooling important?

Creating DB connections is expensive.

43. What happens without pooling?

High latency.

Resource waste.

44. How does SQLAlchemy handle pooling?

Automatically through Engine.

45. What is pool exhaustion?

All connections are busy.

New requests must wait.
