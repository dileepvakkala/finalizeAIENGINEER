Customer Model
class Customer(Base):

    __tablename__ = "customers"

    id = Column(
        Integer,
        primary_key=True
    )

    kyc = relationship(
        "KYC",
        back_populates="customer",
        uselist=False
    )
KYC Model
class KYC(Base):

    __tablename__ = "kyc"

    id = Column(
        Integer,
        primary_key=True
    )

    customer_id = Column(
        Integer,
        ForeignKey(
            "customers.id"
        ),
        unique=True
    )

    customer = relationship(
        "Customer",
        back_populates="kyc"
    )

Session 3 (4 PM – 6 PM)
Performance Optimization
N+1 Query Problem

Bad:

customers = (
    db.query(Customer)
    .all()
)

for customer in customers:

    print(
        customer.accounts
    )

Generated:

1 Query Customers

100 Queries Accounts

Total:

101 Queries
Solution: joinedload()
from sqlalchemy.orm import (
    joinedload
)
customers = (

    db.query(Customer)

    .options(
        joinedload(
            Customer.accounts
        )
    )

    .all()
)

Generated:

Single Query
Lazy Loading

Default:

customer.accounts

loads only when accessed.

Eager Loading
joinedload()

loads immediately.
