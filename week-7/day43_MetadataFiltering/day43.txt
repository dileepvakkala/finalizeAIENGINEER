Day 43 – Metadata Filtering (Production RAG)

Today you'll learn a feature that almost every enterprise RAG system uses.

Without metadata filtering:

User Query
    ↓
Vector Search
    ↓
Search Entire Database
    ↓
Results

With metadata filtering:

User Query
    ↓
Metadata Filter
    ↓
Relevant Documents Only
    ↓
Vector Search
    ↓
Results

This improves:

Accuracy
Speed
Security
Relevance
Why Metadata Filtering?

Imagine a Banking RAG system containing:

Home Loan Policies
Vehicle Loan Policies
Credit Card Policies
Insurance Policies
HR Policies
Compliance Documents

User asks:

What documents are needed for a home loan?

Without filtering:

Retriever may return:

Vehicle Loan
Insurance
Credit Card

With filtering:

document_type = home_loan

Only relevant documents are searched.

What is Metadata?

Metadata is data about data.

Document:

Home Loan Policy 2025

Content:

Interest Rate: 8%

Eligibility:
Salary > 50000

Metadata:

{
  "document_type": "home_loan",
  "year": 2025,
  "department": "retail_banking",
  "region": "india"
}
Session 1 (6 AM – 8 AM)
Adding Metadata

LangChain Document:

from langchain_core.documents import Document

doc = Document(
    page_content="""
    Home Loan Interest Rate: 8%
    """,
    metadata={
        "loan_type":"home_loan",
        "year":2025
    }
)
Multiple Documents
documents = [
    Document(
        page_content="Home Loan Policy",
        metadata={
            "type":"home_loan"
        }
    ),

    Document(
        page_content="Vehicle Loan Policy",
        metadata={
            "type":"vehicle_loan"
        }
    )
]
Store in Chroma
vectorstore.add_documents(
    documents
)
Searching Without Filter
results = vectorstore.similarity_search(
    "interest rate"
)

Searches everything.

Searching With Filter
results = vectorstore.similarity_search(
    "interest rate",
    filter={
        "type":"home_loan"
    }
)

Only home-loan documents searched.

Interview Questions
What is Metadata?

Information describing a document.

Why is Metadata Filtering important?

It narrows search to relevant documents before retrieval.

What are common metadata fields?
Document Type
Department
Country
Region
Year
Access Level
Does Metadata Filtering improve performance?

Yes.

Search is performed on fewer documents.

Does Metadata Filtering improve accuracy?

Yes.

Irrelevant chunks are excluded.

How is Metadata stored?

Alongside document chunks in the vector database.

What is Dynamic Metadata Filtering?

Filters generated automatically from user queries.

Can Metadata be used for security?

Yes.

Role-based access control is a common enterprise use case.

How does Metadata Filtering work with Parent-Child Retrieval?

Filter first, then search child chunks, then fetch parent chunks.

Which vector databases support metadata filtering?
ChromaDB
Pinecone
Weaviate
Qdrant
