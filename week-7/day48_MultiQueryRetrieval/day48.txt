Day 48 – Multi Query Retrieval (Advanced RAG)

Multi Query Retrieval is one of the most effective ways to improve retrieval quality in RAG systems.

A single user query may not contain all the keywords or semantic variations needed to find the best documents.

Instead of searching once:

User Query
    ↓
Retriever
    ↓
Results

Search multiple variations:

User Query
    ↓
LLM Generates Multiple Queries
    ↓
Query 1
Query 2
Query 3
Query 4
    ↓
Retriever
    ↓
Merge Results
    ↓
LLM
Why Multi Query Retrieval?

Suppose the user asks:

Home loan eligibility

Relevant documents may contain:

Home loan requirements
Loan qualification criteria
Minimum salary requirements
Home loan approval conditions

A single query may miss some documents.

Multiple queries improve recall.

Problem with Single Query Retrieval

User Query:

Home loan eligibility

Retriever finds:

Eligibility Criteria

But misses:

Qualification Rules
Approval Conditions
Income Requirements
Multi Query Retrieval Solution

Generate:

What are home loan eligibility criteria?

What are home loan qualification requirements?

What salary is needed for a home loan?

What conditions are required for home loan approval?

Search all of them.

LangChain MultiQueryRetriever

Install:

pip install langchain

Basic Example:

from langchain.retrievers.multi_query import MultiQueryRetriever

multi_query_retriever = (
    MultiQueryRetriever.from_llm(
        retriever=vectorstore.as_retriever(),
        llm=llm
    )
)

Search:

docs = multi_query_retriever.invoke(
    "home loan eligibility"
)

Custom Query Prompt
from langchain.prompts import PromptTemplate

QUERY_PROMPT = PromptTemplate(
    input_variables=["question"],
    template="""
Generate 5 different search queries
for the following question:

{question}
"""
)

Use Custom Prompt:

multi_query_retriever = (
    MultiQueryRetriever.from_llm(
        retriever=retriever,
        llm=llm,
        prompt=QUERY_PROMPT
    )
)

Interview Questions
What is Multi Query Retrieval?

A retrieval technique where multiple search queries are generated from a single user query.

Why use Multi Query Retrieval?

To improve recall and retrieve documents that use different wording.

How does it improve retrieval?

Different query formulations discover different relevant documents.

What are the disadvantages?
Higher latency
Higher retrieval cost
Potential query drift
How many queries should typically be generated?

Usually 3–5.

What is query drift?

When generated queries change the meaning of the original question.

Why deduplicate results?

Multiple queries may return the same documents.

How does Multi Query Retrieval differ from Query Expansion?
Query Expansion	Multi Query Retrieval
Adds keywords	Creates separate queries
Single search	Multiple searches
Lower cost	Higher recall
Where is Multi Query Retrieval used?
Banking RAG
Legal Search
Insurance Systems
Enterprise Knowledge Bases
Compliance Search
Goldman Sachs Style Questions

Why not use only one query?

A single query may not capture all terminology used in documents.

What is the biggest challenge?

How would you optimize Multi Query Retrieval?
Generate 3–5 queries
Apply metadata filtering
Use hybrid search
Re-rank results
Compress context
When should Multi Query Retrieval be avoided?

When:

Dataset is very small
Latency requirements are extremely strict
Query is already highly specific
