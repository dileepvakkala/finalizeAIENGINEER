Today you'll learn one of the most powerful RAG optimization techniques.

Many retrieval failures happen because the user query is not the best query for the retriever.

Query Transformation rewrites the user query into a form that improves retrieval quality.

Why Query Transformation?

User asks:

What documents do I need?

Retriever problem:

Need for what?
Home Loan?
Vehicle Loan?
Credit Card?

Very ambiguous.

Better query:

What documents are required for a Home Loan application?

Retrieval becomes much better.

Interview Questions
What is Query Transformation?

A process of rewriting or enhancing a query to improve retrieval quality.

Why is Query Transformation important?

User queries are often ambiguous, short, or incomplete.

What is Query Expansion?

Adding related terms to improve recall.

What is Multi Query Retrieval?

Generating multiple search queries from one user query.

What is Step Back Prompting?

Generating a broader query to retrieve more context.

What is HyDE?

Hypothetical Document Embeddings.

Generate a hypothetical answer and use its embedding for retrieval.

What is Self Query Retriever?

A retriever that automatically extracts metadata filters from user queries.

When should Multi Query Retrieval be used?

Complex domains such as banking, insurance, legal, and compliance documents.

How does Query Transformation reduce hallucinations?

It improves retrieval quality, leading to better grounding context.
