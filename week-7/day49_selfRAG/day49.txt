Day 49 – Self Query Retriever (Metadata-Aware Retrieval)

Today you'll learn one of the most important enterprise RAG techniques.

Self Query Retriever allows an LLM to automatically extract metadata filters from a user's query and apply them to vector search.

This is heavily used in:

Banking Systems
Insurance Platforms
Legal Search
Compliance Applications
Enterprise Knowledge Bases
Problem Without Self Query Retriever

Suppose your vector DB contains:

Home Loan Policy 2024
Home Loan Policy 2025
Vehicle Loan Policy 2025
Credit Card Policy 2025

User asks:

Show home loan policies from 2025

Without metadata filtering:

Retriever

↓

Returns:
Home Loan 2024
Home Loan 2025
Vehicle Loan 2025

Not ideal.

Solution

LLM extracts:

{
  "loan_type": "home_loan",
  "year": 2025
}

Then applies filters before retrieval.

For Banking Project:

Session 2 (11 AM – 1 PM)
LangChain SelfQueryRetriever

Install:

pip install langchain

Import

from langchain.retrievers.self_query.base import (
    SelfQueryRetriever
)

Define Metadata Fields

from langchain.chains.query_constructor.schema import AttributeInfo

metadata_field_info = [
    AttributeInfo(
        name="loan_type",
        description="Type of loan",
        type="string"
    ),

    AttributeInfo(
        name="year",
        description="Policy year",
        type="integer"
    )
]

Create Retriever

retriever = SelfQueryRetriever.from_llm(
    llm=llm,
    vectorstore=vectorstore,
    document_contents="Banking Policies",
    metadata_field_info=metadata_field_info
)

Search

docs = retriever.invoke(
    "Show home loan policies from 2025"
)

Internally Generated

{
  "query": "home loan policies",
  "filter": {
      "loan_type":"home_loan",
      "year":2025
  }
}
ChromaDB Filter Example
results = collection.query(
    query_texts=["loan policy"],
    where={
        "loan_type":"home_loan",
        "year":2025
    }
)

Interview Questions
What is Self Query Retrieval?

A retrieval technique where an LLM automatically extracts metadata filters from user queries.

Why use Self Query Retriever?

To combine semantic search with structured filtering.

What does Self Query Retriever generate?

What is metadata-aware retrieval?

Retrieval that uses document metadata in addition to embeddings.

What are common metadata fields?

Policy Year
Country
Department

How does Self Query Retriever improve retrieval quality?

It narrows search to relevant documents before retrieval.

Can Self Query Retriever work with vector databases?

What is the biggest challenge?
