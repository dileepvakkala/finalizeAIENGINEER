Day 44 – Hybrid Search (BM25 + Vector Search)

Today you'll learn one of the most important production RAG optimization techniques.

Many RAG systems fail because they rely only on vector search.

Problem with Pure Vector Search

User asks:

What is ROI for home loan?

Document contains:

ROI = Rate Of Interest

Vector search may miss the exact acronym.

User asks:

What is section 80C deduction?

Document contains:

Income Tax Act Section 80C

Keyword matching is important.

Problem with Pure Keyword Search

User asks:

Can I get tax benefits on my house loan?

Document contains:

Home loan interest deduction available under section 24.

Keyword search may miss semantic meaning.

Solution: Hybrid Search

Combine:

BM25 (Keyword Search)

+

Vector Search (Semantic Search)

LangChain BM25 Example
from langchain_community.retrievers import BM25Retriever

retriever = BM25Retriever.from_documents(
    documents
)

retriever.k = 5

Search

results = retriever.invoke(
    "home loan interest"
)

Ensemble Retriever

LangChain Hybrid Search.

from langchain.retrievers import (
    EnsembleRetriever
)

ensemble_retriever = (
    EnsembleRetriever(
        retrievers=[
            bm25_retriever,
            vector_retriever
        ],
        weights=[0.5, 0.5]
    )
)

Retrieve

results = (
    ensemble_retriever.invoke(
        "home loan documents"
    )
)

Interview Questions
What is BM25?

A keyword-based ranking algorithm used in information retrieval.

What is Dense Retrieval?

Embedding-based semantic search.

Difference Between Sparse and Dense Retrieval?
Sparse	Dense
Keywords	Semantics
BM25	Embeddings
Exact Match	Meaning Match
What is Hybrid Search?

Combining sparse and dense retrieval.

Why is Hybrid Search better?

It captures both keyword matches and semantic similarity.

What is Re-ranking?

A second-stage ranking process that improves retrieval quality.

What is Score Fusion?

Combining BM25 and vector scores.

Why is Hybrid Search useful in Banking?

Banking documents contain:

Acronyms

Regulations
Natural language queries

Hybrid search handles all of them.

How does Hybrid Search improve RAG?

It increases recall and retrieval accuracy.
