from pypdf import PdfReader

def extract_text(
        file_path
):

    reader = PdfReader(
        file_path
    )

    text = ""

    for page in reader.pages:

        text += (
            page.extract_text()
            or ""
        )

    return text

Upload API
from fastapi import (
    UploadFile,
    File,
    BackgroundTasks
)

@app.post("/upload")
async def upload(
        background_tasks:
        BackgroundTasks,

        file: UploadFile
        = File(...)
):

    path = (
        f"uploads/"
        f"{file.filename}"
    )

    with open(
        path,
        "wb"
    ) as buffer:

        buffer.write(
            await file.read()
        )

    background_tasks.add_task(
        process_pdf,
        path
    )

    return {
        "message":
        "Uploaded"
    }

Interview Questions
What are Background Tasks?

Tasks executed after sending the response.

Why use Background Tasks?

Avoid blocking API requests.

Difference Between Async and Background Tasks?

Async:

Waits inside request lifecycle

Background Task:

Runs after response is returned
When should Background Tasks be used?
Emails
Notifications
PDF Processing
Logging
When should Background Tasks NOT be used?

Long-running jobs:

Hours
Large ML Training
Heavy Processing

Use Celery.

What happens if the server crashes?

FastAPI BackgroundTasks are lost.

Production systems use:

Celery
Redis
Message Queues
