Day 29 – Output Parsers (Structured AI Responses)

Today you'll learn one of the most important production GenAI concepts.

In real projects, we rarely want:

"What is home loan?"

↓

A paragraph of text

We usually need:

{
  "loan_type": "Home Loan",
  "interest_rate": "8%",
  "eligibility": "Salary > 50K"
}

Output Parsers convert LLM responses into structured formats that backend systems can process.

This is heavily used in:

Banking AI Assistants
Insurance Claim Processing
Document Extraction
Agentic AI Workflows
Multi-Agent Systems

Session 1 (6 AM – 8 AM)
Why Output Parsers?

Without parser:

response = llm.invoke(
    "What is home loan?"
)

Output:

Home loan is a loan provided...

Hard to use programmatically.

With parser:

{
 "loan_type":"Home Loan",
 "interest_rate":"8%"
}

Easy to process.

StrOutputParser

Most basic parser.

from langchain_core.output_parsers import (
    StrOutputParser
)

Example:

parser = StrOutputParser()

Chain:

chain = prompt | llm | parser

Output:

answer = chain.invoke(
    {
        "question":
        "What is home loan?"
    }
)

print(answer)

Returns:

Plain String

Pydantic Model
from pydantic import BaseModel


class LoanResponse(
    BaseModel
):
    loan_type: str
    interest_rate: str
    eligibility: str
PydanticOutputParser
from langchain.output_parsers import (
    PydanticOutputParser
)

Create Parser:

parser = (
    PydanticOutputParser(
        pydantic_object=
        LoanResponse
    )
)
Format Instructions
parser.get_format_instructions()

Generates instructions for the LLM.

Prompt:

template = """
Answer the question.

{format_instructions}

Question:
{question}
"""
prompt = PromptTemplate(
    input_variables=[
        "question"
    ],
    partial_variables={
        "format_instructions":
        parser.get_format_instructions()
    },
    template=template
)

Run:

result = chain.invoke(
    {
      "question":
      "Explain home loan"
    }
)

Output:

LoanResponse(
    loan_type="Home Loan",
    interest_rate="8%",
    eligibility="Salary > 50K"
)
