What is a Tool?

A Tool is a function that an LLM can call to perform an action.

Example:

User:
What is 50000 * 12?

Without Tool:

LLM guesses answer

With Tool:

LLM
 ↓
Calculator Tool
 ↓
600000
Why Do We Need Tools?

LLMs are good at:

Reasoning
Summarization
Text Generation

LLMs are NOT good at:

Real-time Data
Database Queries
Arithmetic
API Calls

Tools solve this problem.

Session 1 (6 AM – 8 AM)
Simple Tool Example
def calculator(a, b):
    return a + b

Tool:

from langchain.tools import tool

@tool
def calculator(a: int, b: int):
    """Add two numbers"""
    return a + b

Usage:

calculator.invoke({
    "a":10,
    "b":20
})

Output:

30
Custom Banking Tool

Example:

accounts = {
    "1001":50000,
    "1002":70000
}

Tool:

from langchain.tools import tool

@tool
def get_balance(
    account_id: str
):
    """
    Returns account balance
    """

    return accounts.get(
        account_id,
        "Account not found"
    )

Question:

What is balance of account 1001?

Tool returns:

50000

import requests

from langchain.tools import tool

@tool
def get_loan_rate():
    """
    Get current loan rate
    """

    response = requests.get(
        "http://localhost:8000/loan-rate"
    )

    return response.json()

Interview Questions
What is a Tool?

A callable function an LLM can use to perform actions.

Why do we need Tools?

To access external systems and real-time information.

What are common Tool types?
API Tools
Database Tools
Calculator Tools
Search Tools
Retriever Tools
Can Retrievers be Tools?

Yes.

Retriever Tools are widely used in RAG applications.

How does an Agent choose a Tool?

Using tool name, description, and user query.

Difference between Tool and Function?

A Tool is a function exposed to the LLM.

What is Tool Calling?

The process where an LLM invokes a tool to perform a task.

Why are Tools important?

They extend LLM capabilities beyond text generation.

What are Tool descriptions used for?

Helping the model decide which tool to call.

What is a Database Tool?

A tool that queries a database and returns results.
