What is Memory?

Memory allows an AI application to remember information from previous interactions.

Without Memory:

User: My name is Dileep

AI: Nice to meet you

User: What is my name?

AI: I don't know

With Memory:

User: My name is Dileep

AI: Nice to meet you

User: What is my name?

AI: Your name is Dileep
Types of Memory
Memory

├── Short-Term Memory
├── Long-Term Memory
├── Episodic Memory
├── Semantic Memory
├── Working Memory
└── Vector Memory
1. Short-Term Memory

Stores information only during the current conversation/session.

Example:

User:
I want a home loan

User:
What is the interest rate?

The AI understands:

interest rate
=
home loan interest rate

because the earlier message is still available.

Characteristics

✅ Fast

✅ Session-based

✅ Temporary

❌ Lost after session ends

Banking Example
User:
Show account 123

User:
What is its balance?

"its" refers to account 123.

2. Long-Term Memory

Stores information across sessions.

Example:

User:
My preferred language is Telugu

Store in database.

Next week:

User:
Generate report

AI automatically uses Telugu.

Storage Options
PostgreSQL
MySQL
Redis
MongoDB
Vector DB
Banking Example

3. Working Memory

Information currently being processed.

Example:

Question:
Calculate EMI for
50 lakh loan

The intermediate calculations are working memory.

Similar To

Computer RAM.

Stores experiences/events.

Knowledge Base

Stores memory as embeddings.

Example:

Conversation:

about home loans.

Convert to vector.

Store in:

Memory Types Used in Applications
Conversation Buffer Memory

Stores all messages.

Example:

User: Hello

AI: Hi

User: Loan details

AI: ...

Everything remains.

Problem

Large token usage.

Conversation Window Memory

Stores only recent messages.

Example:

Last 5 Messages

Older messages removed.

Benefits
Lower Cost
Faster
Conversation Summary Memory

Stores summarized history.

Instead of:

100 Messages

Store:

Customer interested
in home loan
Benefits
Very Low Tokens
Long Conversations

Interview Questions
What is Memory in LLM applications?

Mechanism for retaining and using previous information.

Difference between Short-Term and Long-Term Memory?
Short-Term	Long-Term
Session only	Across sessions
Temporary	Persistent
Faster	Stored externally
What is Working Memory?

Temporary information used during reasoning.

What is Episodic Memory?

Memory of events and experiences.

What is Semantic Memory?

Facts and knowledge.

Why is memory important?

Maintains context and improves user experience.

How is memory implemented?

Store conversation history and include relevant history in prompts.

What is Conversation Buffer Memory?

Stores entire conversation.

What is Window Memory?

Stores only recent messages.

What is Summary Memory?

Stores compressed conversation summaries.

What is Vector Memory?

Stores memory as embeddings for semantic retrieval.

Goldman Sachs / Enterprise Interview Questions
How would you implement memory for a banking chatbot?
Store chat history in PostgreSQL or Redis
Retrieve relevant history
Add history to prompt
Update memory after each interaction
Why not store all messages forever?
High token cost
Slow responses
Context window limits
How would you handle very long conversations?

Use summary memory + recent window memory.

What is the best memory strategy?

Hybrid:

Recent Messages
       +
Summary
       +
Vector Memory

RAG	Memory
Retrieves documents	Retrieves conversation history
External knowledge	User context
Knowledge base	Chat history
