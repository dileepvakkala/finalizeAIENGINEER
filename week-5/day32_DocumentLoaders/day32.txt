What is a Document Loader?

A Document Loader reads files and converts them into LangChain Document objects.

Without Loader:

with open("policy.txt") as f:
    text = f.read()

Manual process.

With Loader:

loader = TextLoader(
    "policy.txt"
)

documents = loader.load()
What is a Document Object?

LangChain stores data as:

Document(
    page_content="Home loan interest rate is 8%",
    metadata={
        "source":"policy.pdf"
    }
)

Text Loader

Install:

pip install langchain-community

Example:

from langchain_community.document_loaders import (
    TextLoader
)

loader = TextLoader(
    "loan_policy.txt"
)

docs = loader.load()

Output:

[
 Document(
   page_content="...",
   metadata={}
 )
]
PDF Loader

Most common in RAG.

Install:

pip install pypdf

Example:

from langchain_community.document_loaders import (
    PyPDFLoader
)

loader = PyPDFLoader(
    "home_loan_policy.pdf"
)

docs = loader.load()

Result:

[
 Document(page1),
 Document(page2),
 Document(page3)
]

Each page becomes a document.
