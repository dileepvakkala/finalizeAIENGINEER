Session 2 (11 AM – 1 PM)
Prompt Templates

Prompt engineering is central to GenAI.

Without Template
query = "What is home loan?"
With Template
from langchain.prompts import PromptTemplate

prompt = PromptTemplate(
    input_variables=["question"],
    template="""
    You are a banking assistant.

    Question:
    {question}

    Answer:
    """
)
Format Prompt
formatted = prompt.format(
    question="What is home loan?"
)

print(formatted)

Output:

You are a banking assistant.

Question:
What is home loan?

Answer:
Models

Example:

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini"
)
Invoke Model
response = llm.invoke(
    "What is home loan?"
)

print(response.content)
Session 3 (4 PM – 6 PM)
Chains & LCEL
What is a Chain?

A chain connects components.

Example:

Prompt
   ↓
LLM
   ↓
Output
LCEL (LangChain Expression Language)

Modern LangChain style.

chain = prompt | llm

Execute:

result = chain.invoke(
    {
        "question":
        "What is home loan?"
    }
)

print(result.content)
Output Parser

Without parser:

AIMessage(...)

With parser:

from langchain_core.output_parsers import (
    StrOutputParser
)

parser = StrOutputParser()

Chain:

chain = (
    prompt
    | llm
    | parser
)

Result:

answer = chain.invoke(
    {
        "question":
        "What is home loan?"
    }
)

Returns:

Plain Text
