Day 28 – Chains (LangChain Chains & LCEL)

Today you'll learn how to connect multiple GenAI components into a workflow.

This is one of the most important LangChain concepts because real-world applications are not just:

Question → LLM

Instead they are:

Question
   ↓
Retriever
   ↓
Prompt
   ↓
LLM
   ↓
Parser
   ↓
Response

This complete flow is called a Chain.

Session 1 (6 AM – 8 AM)
What is a Chain?

A Chain connects multiple LangChain components.

Without Chain:

prompt = prompt_template.format(
    question="What is home loan?"
)

response = llm.invoke(prompt)

answer = response.content

With Chain:

chain = prompt | llm | parser

Flow:

Prompt
  ↓
LLM
  ↓
Parser
Install
pip install langchain
pip install langchain-openai
Basic Chain
from langchain.prompts import PromptTemplate

prompt = PromptTemplate(
    input_variables=["question"],
    template="""
    Answer:

    {question}
    """
)
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini"
)
from langchain_core.output_parsers import (
    StrOutputParser
)

parser = StrOutputParser()

Create Chain:

chain = prompt | llm | parser

Run:

result = chain.invoke(
    {
        "question":
        "What is home loan?"
    }
)

print(result)
LCEL

LCEL = LangChain Expression Language.

Modern LangChain uses:

prompt | llm | parser

instead of older chain classes.

Benefits:

Readable
Reusable
Composable
Production Friendly
Session 2 (11 AM – 1 PM)
Multi-Step Chains

Real systems require multiple steps.

Example:

Question
   ↓
Generate Query
   ↓
Retrieve Documents
   ↓
Generate Answer
Example Prompt
query_prompt = PromptTemplate(
    input_variables=["question"],
    template="""
    Convert question into search query.

    Question:
    {question}
    """
)

Chain:

query_chain = (
    query_prompt
    | llm
    | parser
)

Input:

query_chain.invoke(
    {
      "question":
      "What is mortgage interest?"
    }
)

Output:

home loan interest rate
RunnableLambda

Custom Python logic inside chain.

from langchain_core.runnables import (
    RunnableLambda
)

Example:

def uppercase(text):
    return text.upper()
custom_step = RunnableLambda(
    uppercase
)

Chain:

chain = (
    prompt
    | llm
    | parser
    | custom_step
)
