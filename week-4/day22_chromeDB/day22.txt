What is an Embedding?

Embedding = Numerical representation of text.

Example:

"Bank Loan"

↓

[0.23, 0.45, 0.11, ...]
Similar Texts
Home Loan

Housing Loan

Mortgage Loan

produce similar vectors.

Why Vector DB?

Stores:

Text
Vector
Metadata

and performs:

Semantic Search
Session 2 (11 AM – 1 PM)
ChromaDB Installation
Install
pip install chromadb
Create First Database
import chromadb

client = chromadb.PersistentClient(
    path="./chroma_db"
)
Create Collection

Collection = Table equivalent.

collection = client.create_collection(
    name="bank_docs"
)
Add Documents
collection.add(
    ids=["1"],

    documents=[
        "Home loan interest rate is 8%"
    ]
)
Query Documents
results = collection.query(
    query_texts=[
        "housing loan"
    ],
    n_results=1
)

print(results)

Full Example
import chromadb

client = chromadb.PersistentClient(
    path="./chroma_db"
)

collection = client.get_or_create_collection(
    name="bank_docs"
)

collection.add(

    ids=["1","2"],

    documents=[
        "Home loan interest is 8%",
        "Credit card interest is 20%"
    ]
)

result = collection.query(

    query_texts=[
        "housing loan"
    ],

    n_results=1
)

print(result)

Interview Questions
What is ChromaDB?

Open-source vector database for storing embeddings and performing similarity search.

Why use ChromaDB?

For semantic search in RAG applications.

What is a Vector Database?

Database optimized for storing vectors and similarity searching.

Difference between PostgreSQL and ChromaDB?
PostgreSQL	ChromaDB
Exact search	Semantic search
Structured data	Embeddings
SQL queries	Similarity search
What is an Embedding?

Numerical representation of text.

Why are embeddings useful?

Capture semantic meaning.

What is Similarity Search?

Finding vectors closest to query vector.

What is a Collection?

Equivalent to a table in ChromaDB.

What is Metadata?

Additional information stored with documents.

Example:

{
 "type":"loan"
}
What is RAG?

Retrieval-Augmented Generation.

Retrieve relevant documents before sending context to the LLM.
