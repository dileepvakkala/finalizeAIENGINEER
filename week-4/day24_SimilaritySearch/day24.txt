FastAPI Similarity Search API
Request Model
from pydantic import BaseModel

class QueryRequest(
    BaseModel
):
    question: str
API
from fastapi import APIRouter

router = APIRouter()

@router.post("/search")
def search_docs(
    request:
    QueryRequest
):

    result = (
        collection.query(
            query_texts=[
                request.question
            ],
            n_results=3
        )
    )

    return result

Interview Questions
What is Similarity Search?

Finding documents closest in meaning to a query.

Why use similarity search?

To retrieve semantically relevant information.

Difference between keyword search and similarity search?

Keyword:

Exact words

Similarity:

Meaning-based retrieval
What is Cosine Similarity?

Measures similarity between vectors.

Why use Top-K retrieval?

Provides multiple relevant contexts for the LLM.

What is Metadata Filtering?

Restrict retrieval to specific document categories.

What are vector distances?

Measure closeness between embeddings.

Why not return all matching documents?

Too much context increases token cost and reduces answer quality.

What is Hybrid Search?

Keyword search plus vector search.

What is Re-ranking?

Reordering retrieved results using a stronger model.
